Une carte

Mise en forme : **gras**, indice H_{2}O, exposant Ca^{2+}. Image : bouton « + Image », glisse-la sur le champ, ou colle une capture (Ctrl+V).

Coller des cartes

Colle ici le bloc que Claude te donne après un cours : les paquets sont créés tout seuls. Sinon, une carte par ligne : question ;; réponse.

À la fin d'un cours avec Claude, dis « rajoute-moi des questions sur mon site » : il te donne un bloc à copier, tu le colles dans « Coller des cartes ».

Mot de passe

Tes cartes sont chiffrées avec ton mot de passe avant d'être envoyées sur GitHub. S'il est oublié, elles ne peuvent pas être récupérées.

Connexion GitHub

Le token reste enregistré uniquement dans ce navigateur. Il ne sert qu'à écrire dans ton dépôt de cartes.

Progression

Ta progression est enregistrée sur ce téléphone et, si GitHub est connecté, sauvegardée dans ton dépôt. Tu peux aussi en garder une copie.
